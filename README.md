
# Machine Learning Zoomcamp

My homework solutions, notes, and projects from the [Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp), a hands-on machine learning engineering course by [DataTalks.Club](https://datatalks.club/).

The goal of this repository is to document my progress in machine learning, develop practical skills in Python and machine learning engineering, and apply the concepts covered in the course through hands-on assignments and projects.

## Course Topics

- Machine learning fundamentals and exploratory data analysis
- Regression and classification
- Feature engineering and model evaluation
- Decision trees, random forests, and gradient boosting
- Deep learning and neural networks
- Model deployment and serving
- Docker, serverless deployment, and Kubernetes
- End-to-end machine learning projects
